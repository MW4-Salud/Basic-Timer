# Contributing

1. Fork the repo and clone it.
2. Make a branch off `develop`:
   ```
   git checkout develop
   git checkout -b feature/your-feature
   ```
3. Make your changes and test them by running `python electron_timer.py`.
4. Commit with a short message that says what changed.
5. Open a pull request into `develop`.

`main` only gets updated from `develop` when a new version is ready.
